Privacy Policy

This application is for personal use and does not share your data with third parties.

Goblin Health Local Sync is a single-user tool. It accesses Google Health data belonging to its own operator and to no other account, stores that data in a local SQLite database on the operator's own machine, and transmits it nowhere else.

  • No data is sold, shared, or disclosed to any third party.
  • No analytics, telemetry, or remote logging is performed.
  • No data leaves the machine it runs on, beyond the API requests required to read the operator's own health data from Google.
  • All data can be deleted at any time by deleting the local database file.

Questions or data-deletion requests: open an issue at github.com/cflux/goblin-health-local-sync/issues.
